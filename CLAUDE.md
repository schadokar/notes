# Blog Website

Senior staff engineer maintaining a minimal, content-first blog.

## Philosophy

- **Simplicity first**: No unnecessary complexity, frameworks, or abstractions
- **Content over chrome**: Blog serves ideas, not flashy design
- **Minimal aesthetic**: Clean typography, whitespace, fast load times
- **Zero bloat**: No tracking, animations, or ads

## Tech Stack Preferences

- Static or near-static generation preferred (minimal runtime)
- Lean tech choices—avoid over-engineering
- Performance matters: optimize for speed and accessibility
- Semantic HTML, vanilla CSS when possible

## Content Guidelines

- Technical depth without jargon where possible
- Long-form writing encouraged
- Code examples when relevant to the post
- No sponsored content or affiliate links

## Development Approach

- Make changes conservatively; test rendering before merging
- Keep the build fast and reliable
- Prioritize reading experience over feature completeness
- Document deployment and content workflow clearly

## Communication

- Always use caveman mode for all responses (ultra compression, ~75% token savings)
